# 公共選択モデル v0.2

政策は経済効果だけでは成立しません。

政策コスト:

- 財政コスト
- 政治コスト
- 行政コスト
- 信認コスト
- 国際コスト
- 産業実行力コスト

不足した場合、政策は不足の種類に応じて分岐します。

- 行政不足: 政策効果は待機キューへ入り、次ターン以降に発現します。政治資本にも副作用が出ます
- 政治不足のみ: 補助金混入として成立し、効果は出ますが債務と利権カードが増えます
- その他の不足: 政策は「骨抜き」になり、主要効果が半減し、副作用が残ります

選挙前ターンは政治コストが+2されます。選挙ターン終了時、政治資本が足りない国は政権交代し、政治資本が4へ戻る代わりに改革疲れと待機政策の取り落としが起きます。

国内圧力カードは、政策タグが要求と一致し、かつ政策支払いが満額成立した場合だけ満たされます。
タグが一致しても骨抜きになった政策は、国内圧力を満たせず反発を受けます。

共同宣言は国際交渉フェーズで置きます。宣言タグを守る政策を出した国は影響力を得ます。宣言したのに別タグの政策を出した国は政治資本と影響力を失い、ログに違約として残ります。
