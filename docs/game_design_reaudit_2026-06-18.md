# マクロノミカ ゲームデザイン再点検（2026-06-18）

## 結論

現行実装は、コア設計としては v0.2 正本に近づいている。
旧式の混合政策デッキは廃止され、政策は `policy_catalog_deck` から生成される `active_agenda`、
国家の歴史・呪いは状態デッキに分離されている。
ただし、テストプレイ体験としては「ゲームが成立している」と言い切れる手前だった。

理由はルールの不足ではなく、UI がゲームの行為を邪魔していたためである。

```text
1. 4国分の政策・ワーカーを毎回すべて手操作する必要があり、テストプレイが重い
2. 解決フェーズが6段階表示なのに、何を読む画面か分かりにくい
3. 政策メニューを全量展開する設計のため、危機政策追加時にカードが枠からあふれうる
4. 政策メニューが「巨大な手札」に見え、政策カタログと政策議題の区別が伝わりにくい
```

したがって、2026-06-18 の修正では「ゲーム性そのもの」より先に、
ゲーム性を検証できる操作導線を優先して直した。

## 今回の実装修正

```text
政策議題：
  政策カタログデッキから生成された今ターンの候補だけを大きく表示する。
  カードを小さくして詰め込まない。全政策カタログは主操作面ではなく参照情報として扱う。

テストプレイ補助：
  小さな「助」ボタンを廃止し、進行ボタン横の大きな「全員政策 / 全員配置 / 一括解決」ボタンに変更。
  政策計画では全員の政策を自動選択してワーカー配置へ進む。
  ワーカー配置では全員のワーカーを自動配置して同時公開へ進む。
  解決中はレビューを飛ばしてターンを一括解決できる。

解決フェーズ：
  解決レビューのパネルを拡大し、「次=1段階ずつ読む / 自動=一括解決」を明示。
  詳細を読むプレイと、テストプレイで飛ばすプレイを分離した。
```

## 政策カードの作り方の再整理

政策は状態カードと混ぜて引くカードではない。
国家構成から生成される「政策カタログデッキ」であり、毎ターンの選択肢はそこから作られる「政策議題」である。
そのため、政策カード設計では以下を守る。

```text
1. 共通政策は少数の基本レバーに限る
   財政、金融、通商、産業、協調など、学習上必要な骨格だけにする。

2. モジュール政策は国家差を出すために入れる
   「輸出工業国だから為替・産業政策が強い」
   「外貨債務国だから資本規制・債務再編が重要」
   という差を政策カタログに刻む。

3. 危機政策は常設しない
   世界イベントや危機で政策カタログへ追加し、以後の政策議題に上がりうる。
   これにより、同じ国家でも危機時に選択肢が変わる。

4. 1政策1役割を守る
   1枚のカードに複数の教材概念を詰め込みすぎない。
   「需要刺激」「信認回復」「近隣窮乏」「危機支援」など、主語を明確にする。

5. 政策議題は最大7枚に絞る
   UI上は今ターンの議題だけを大きく見せる。
   政策カタログ全体は参照/デブリーフ/国家構成確認に退避する。
```

この方針なら、「旧式の混合政策デッキ廃止」と「国家構成から政策が生まれる」は両立する。
政策は状態デッキから引くものではなく、国家の制度・産業構造・政治制約から政策カタログに入り、
その時々の国内情勢・圧力・交渉・危機によって政策議題へ上がる選択肢である。

## まだ残るゲームデザイン上の確認事項

```text
- 自動プレイで10ターン回したとき、全員敗北・厚生点・国際影響力が意味のある分散を作るか
- 政策カタログが各国で十分に違うか。同じ政策の並びに見えすぎないか
- 解決レビューを読んだプレイヤーが「政策 → 圧力 → コスト → 国内/世界効果 → 状態デッキ変質」を追えるか
- 危機政策の追加が政策議題として実感できる頻度で現れるか
```

次のゲームデザイン検証は、手操作ではなく `全員政策 / 全員配置 / 一括解決` を使って
複数ターンを素早く回し、上記4点を観察する。
