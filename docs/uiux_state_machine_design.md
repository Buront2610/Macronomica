# マクロノミカ UI/UX状態遷移設計

作成日: 2026-06-07

この文書は、`マクロノミカ` のメイン卓上UIをボードゲームとして再構築するための設計書である。既存UIの問題は、情報をパネルとして並べた結果、ゲームの中心である「伏せ札」「担当印」「同時公開」「世界波及」が盤面上の出来事として見えなくなったことにある。

以後のUI実装は、本書を優先する。

## 1. 基本方針

メイン体験は、1枚の卓上ボードで完結させる。

ゲーム中は画面を何度も切り替えない。タイトル、国家選択、最終スコア以外は原則としてメイン卓上に滞在し、状態変化はカード、駒、トークン、印章、トラック、新聞が卓上で動くことで表す。

### 非交渉ルール

- メイン卓上をデータアプリにしない。
- 世界トラック、国家状態、スコア、ログを表として常時表示しない。
- 数値は主情報ではなく、詳細確認時の補助情報にする。
- ログで説明せず、まず盤面変化で説明する。
- ワーカーは国に置かない。提出された政策案に押す担当印として扱う。
- 政策名は同時公開まで隠す。ワーカー印は公開情報にする。
- `推奨` はテストプレイ補助であり、主ボタンにしない。

### 目標体験

プレイヤーは経済指標管理者ではなく、危機下の国家代表として振る舞う。

1. 世界情勢カードがめくられる。
2. 各国に国内圧力カードが配られる。
3. 国際交渉で協調案を読む。
4. 各国が政策メニューから政策を1枚選び、伏せて提出する。
5. 各国が政策案に担当印を押す。
6. 4枚の伏せ札が同時公開される。
7. 国内圧力、政策コスト、国内効果、世界波及、デッキ変質が盤上で処理される。
8. 結果は新聞見出しとしてまとめる。

## 2. ゲーム進行との対応

既存ルール上のターン進行は以下。

1. 世界イベント公開
2. 国内情勢更新
3. 国際交渉
4. 政策計画
5. ワーカー配置
6. 同時公開
7. 政策成立判定
8. 国際波及処理
9. マクロ指標更新
10. 国内政治処理
11. デッキ変質処理

Godot MVPでは、世界イベント公開と国内情勢更新はターン開始時に自動処理される。UIではこれを省略せず、卓上演出として見せる。プレイヤー操作としては `国際交渉 -> 政策計画 -> ワーカー配置 -> 同時公開 -> 解決` が中心になる。

## 3. メイン卓上の画面構造

推奨構造:

```text
┌──────────────────────────────────────────────┐
│ タイトル / ターン / フェーズトラック / 小メニュー          │
├──────────────────────────────────────────────┤
│ [世界イベント]     [世界危機ボード]          [新聞/補助] │
│                                                  │
│ [A国席]          [国際交渉エリア]             [B国席] │
│                                                  │
│ [C国席]          [提出札/公開卓]               [D国席] │
│                                                  │
│ [選択国の手札ファン]            [ワーカー印章トレイ]      │
└──────────────────────────────────────────────┘
```

### 表示優先順位

1. 今何をするか
2. 現在操作中の国
3. 国内圧力
4. 政策案スロット
5. 担当印スロット
6. 世界危機ボード
7. 手札
8. 交渉カード
9. 新聞見出し
10. 詳細数値

詳細数値、完全ログ、最終スコア予測はメイン卓上の主役にしない。

## 4. 主要コンポーネント

### 4.1 国家席

国家席は小型ダッシュボードではなく、国家マットとして扱う。

常時表示するもの:

- 国名/国章
- 国家タイプ
- 国内圧力カード
- 政策案スロット
- 担当印スロット
- 危機チップ 2から4個
- 山札/捨て札の小アイコン

常時表示しないもの:

- 8種国家トラックの詳細数値
- 長文説明
- スコア詳細

国家席の基本形:

```text
┌────────────────────┐
│ A国 基軸通貨・金融大国      │
│ [国内圧力カード]             │
│                              │
│ [政策案スロット] [担当印]     │
│  伏せ札/公開札     ワーカー印  │
│                              │
│ [危機チップ] [山札] [捨札]    │
└────────────────────┘
```

### 4.2 政策案スロット

政策案スロットはこのUIの中心である。

空状態:

```text
┌────────────┐
│ ここに政策案を提出 │
│                    │
│ [担当印 空]         │
└────────────┘
```

政策提出後:

```text
┌────────────┐
│ 伏せ札              │
│ [裏向き政策カード]   │
│ [担当印 空]          │
└────────────┘
```

ワーカー配置後:

```text
┌────────────┐
│ 伏せ札              │
│ [裏向き政策カード]   │
│ [外交官 印]          │
└────────────┘
```

同時公開後:

```text
┌────────────┐
│ 国際スワップライン   │
│ 金融不安 - / 協調 +  │
│ [外交官 印]          │
└────────────┘
```

### 4.3 ワーカー印章

ワーカーは政策案に紐づく担当印として扱う。

- 官僚団: 行政コスト軽減
- 中銀スタッフ: 信認コスト軽減、金融ストレス抑制
- 外交官: 国際コスト軽減、協調強化
- 監査官: 汚職/レント系汚染抑制
- ロビイスト: 政治コスト軽減、利権カード追加リスク

公開情報:

- ワーカー印は同時公開前から見える。
- 政策カード名は同時公開まで見えない。

これにより、同時公開前に「外交官を置いたから協調系かもしれない」「ロビイストなら政治コストの重い政策かもしれない」という読み合いが生まれる。

### 4.4 世界危機ボード

世界トラックは表にしない。中央世界ボード上の危機メーターとして扱う。

世界トラック:

- 世界需要
- 世界金利
- 貿易開放度
- 国際金融不安
- 世界恐慌
- 保護主義
- 国際協調

見た目の原則:

- トラックは地図上の縦メーター、針、チップで表す。
- ラベルは短くする。
- 変化時だけ数値差分を小さく表示する。
- 改善は青/金、悪化は赤/黒で示す。

### 4.5 国内圧力カード

国内圧力は意思決定の源泉であり、国家席で強く見せる。

盤面上の短縮表示:

```text
雇用対策要求
求: 雇用 / 財政
無視: 反発
```

詳細はカード拡大で読む。

### 4.6 新聞/議事録

解決ログは縦長ログ欄として常時表示しない。ターン結果は新聞としてまとめる。

例:

```text
世界経済新聞

・B国の関税引き上げで保護主義が進行
・A国とD国の協調で金融不安が緩和
・C国、資源価格下落への対応を迫られる
```

完全ログは折りたたみ、または記録帳オーバーレイに置く。

## 6. 実装向け状態名

Godot側では、ルールの `GameState.PHASES` とは別にUI状態を持つ。

```gdscript
enum GameUiState {
	BOOT,
	TITLE,
	COUNTRY_SELECT,
	MAIN_BOARD_READY,
	TURN_START_CLEANUP,
	WORLD_EVENT_REVEAL,
	DOMESTIC_PRESSURE_REVIEW,
	NEGOTIATION,
	POLICY_PLANNING_AWAIT,
	POLICY_PLANNING_SUBMIT_ANIMATING,
	WORKER_ASSIGNMENT_AWAIT,
	WORKER_ASSIGNMENT_STAMPING,
	SIMULTANEOUS_REVEAL_READY,
	SIMULTANEOUS_REVEAL_ANIMATING,
	RESOLUTION_DOMESTIC_PRESSURE,
	RESOLUTION_COSTS,
	RESOLUTION_COUNTRY_EFFECTS,
	RESOLUTION_WORLD_SPILLOVERS,
	RESOLUTION_DECK_MUTATION,
	RESOLUTION_MACRO_FEEDBACK,
	TURN_SUMMARY,
	FINAL_SCORE
}
```

国ごとの操作は `active_country_index` で管理する。

```gdscript
var active_country_index := 0
```

政策計画:

```text
POLICY_PLANNING_AWAIT, active_country_index = 0
POLICY_PLANNING_AWAIT, active_country_index = 1
POLICY_PLANNING_AWAIT, active_country_index = 2
POLICY_PLANNING_AWAIT, active_country_index = 3
```

ワーカー配置:

```text
WORKER_ASSIGNMENT_AWAIT, active_country_index = 0
WORKER_ASSIGNMENT_AWAIT, active_country_index = 1
WORKER_ASSIGNMENT_AWAIT, active_country_index = 2
WORKER_ASSIGNMENT_AWAIT, active_country_index = 3
```

## 7. 入力イベントと遷移

```text
on_start_pressed()
  TITLE -> COUNTRY_SELECT

on_country_setup_confirmed()
  COUNTRY_SELECT -> TURN_START_CLEANUP

on_world_event_confirmed()
  WORLD_EVENT_REVEAL -> DOMESTIC_PRESSURE_REVIEW

on_domestic_pressure_confirmed()
  DOMESTIC_PRESSURE_REVIEW -> NEGOTIATION

on_negotiation_finished()
  NEGOTIATION -> POLICY_PLANNING_AWAIT(active_country_index = 0)

on_policy_card_selected(card)
  POLICY_PLANNING_AWAIT -> POLICY_PLANNING_SUBMIT_ANIMATING

on_policy_submit_animation_finished()
  if active_country_index < 3:
    active_country_index += 1
    -> POLICY_PLANNING_AWAIT
  else:
    active_country_index = 0
    -> WORKER_ASSIGNMENT_AWAIT

on_worker_selected(worker)
  WORKER_ASSIGNMENT_AWAIT -> WORKER_ASSIGNMENT_STAMPING

on_worker_stamp_animation_finished()
  if active_country_index < 3:
    active_country_index += 1
    -> WORKER_ASSIGNMENT_AWAIT
  else:
    -> SIMULTANEOUS_REVEAL_READY

on_reveal_pressed()
  SIMULTANEOUS_REVEAL_READY -> SIMULTANEOUS_REVEAL_ANIMATING

on_reveal_animation_finished()
  SIMULTANEOUS_REVEAL_ANIMATING -> RESOLUTION_DOMESTIC_PRESSURE

on_resolution_step_finished()
  -> next resolution state

on_turn_summary_closed()
  if turn < turn_limit:
    -> TURN_START_CLEANUP
  else:
    -> FINAL_SCORE
```

## 8. 状態別UI仕様

### 8.1 ターン開始

目的: 前ターンの残骸を片付け、新しいターンを始める。

表示:

- 前ターンの公開政策カードを各国捨て札へ送る。
- 担当印をワーカートレイへ戻す。
- 政策案スロットを空にする。
- フェーズマーカーを世界イベントへ戻す。

遷移: 自動で世界イベント公開へ。

### 8.2 世界イベント公開

目的: そのターンの世界情勢を提示する。

表示:

- 世界イベントカードを山札から引き、世界イベント枠に置く。
- 影響する世界トラックを動かす。
- 影響国に衝撃チップを置く。

入力: 確認トークン。

### 8.3 国内圧力確認

目的: 各国が今ターン、国内から何を求められているかを示す。

表示:

- 各国席に国内圧力カードを配る。
- 要求タグだけを短く見せる。
- 満たした場合/無視した場合の詳細は拡大カードに置く。

入力: 交渉へ。

### 8.4 国際交渉

目的: 協調案を読み合い、政策選択前の空気を作る。

表示:

- 中央の交渉カードを強調する。
- 協調刺激、スワップライン、関税凍結などをカードとして並べる。
- 国章チップを交渉カード上に置ける。

入力: 計画へ。

### 8.5 政策計画: 国別

目的: 現在国が政策メニューから政策を1枚選び、伏せ札として提出する。

表示:

- 現在国の国家席を強調。
- 現在国の政策メニューを下部に扇形表示。
- 政策案スロットを点滅。
- 選んだカードをスロットへ移動し、裏向きに固定。

入力: 政策メニューからの政策提出。

### 8.6 ワーカー配置: 国別

目的: 伏せ札に担当印を押す。

表示:

- 現在国の政策案スロットを強調。
- ワーカートレイを表示。
- 選択したワーカー印を担当印スロットへ移動。
- 押印後はワーカー印だけ公開情報として残す。

入力: ワーカー選択/配置。

### 8.7 同時公開待機

目的: 全員が伏せ札と担当印を出した状態を確認する。

表示:

- 4国すべてに裏向きカードと担当印が並ぶ。
- 中央に議長ハンマーまたは公開トークンを置く。

入力: 公開。

### 8.8 同時公開

目的: 4枚の政策を一斉に表にする。

表示:

- 盤面を少し暗くする。
- 4つの政策案スロットだけを強調。
- 4枚同時フリップ。
- ワーカー印は公開カード上に残る。

遷移: 自動で国内圧力判定へ。

### 8.9 国内圧力判定

目的: 政策タグと国内圧力要求の一致/不一致を見せる。

表示:

- 圧力カードと政策カードを線で結ぶ。
- 一致タグを発光。
- 満足ならチェック、無視なら抗議チップ。

### 8.10 政策コスト判定

目的: 政策が成立したか、担当印がどう軽減したかを見せる。

表示:

- 政策カードのコストを点灯。
- ワーカー印を発光。
- 軽減されたコストを消す。
- 成立なら承認印、不足なら骨抜き印。

### 8.11 国内効果適用

目的: 自国への効果を国家席のトークン移動で見せる。

表示:

- 政策カードから国家席へ線を伸ばす。
- GDP、失業、債務、政治資本などをチップ/トークンで動かす。

### 8.12 世界波及適用

目的: 世界トラックや他国への影響を見せる。

表示:

- 政策カードから世界危機ボードへ波及線。
- 該当トラックを動かす。
- 対象国があれば衝撃チップを置く。

### 8.13 デッキ変質

目的: 政策の副作用/遺産がデッキに混ざることを見せる。

表示:

- 政策カードの下から副作用カードを出す。
- 国家捨て札または世界デッキへ滑らせる。
- 良い遺産は青/金、悪い脆弱性は黒/赤。

### 8.14 マクロフィードバック

目的: 複数国の行動が合成されて世界へ二次効果を出すことを見せる。

表示:

- 複数の政策カードから中央へ線が集まる。
- 世界ボード中央で合成エフェクト。
- 関連トラックがまとめて動く。

### 8.15 ターン結果新聞

目的: 長いログではなく、今ターンの結果を3見出しで要約する。

表示:

- 世界経済新聞を右下または中央に出す。
- 見出しを1行ずつ表示。
- 詳細ログは折りたたみ。

## 9. アニメーション原則

アニメーションは飾りではなく、状態変化を理解させるために使う。

良いアニメーション:

- カードがどこから来たか分かる。
- 何がどこへ影響したか分かる。
- どのトークンがなぜ動いたか分かる。
- デッキに何が混ざったか分かる。

避けるもの:

- 常に背景が動く。
- 意味のない発光が多い。
- 長く待たせる。
- クリック対象が動き続ける。
- 結果よりエフェクトが目立つ。

推奨時間:

| 動き | 時間 |
| ---- | ---- |
| 小さな反応 | 0.08から0.12秒 |
| カード移動 | 0.20から0.28秒 |
| カード反転 | 0.14から0.18秒 |
| トークン移動 | 0.20から0.30秒 |
| 波及線 | 0.25から0.35秒 |
| 新聞表示 | 0.25から0.35秒 |
| フェーズ移動 | 0.18から0.25秒 |

1操作の合計は原則1秒以内。同時公開とターン結果だけは少し長くてよい。

## 10. 画面再構築の実装順序

### Step 1: 盤面構造を作り直す

- 右ログ/スコアの常時支配をやめる。
- 中央に世界危機ボードを置く。
- 四隅または左右に4国家席を置く。
- 各国家席に政策案スロットと担当印スロットを作る。

### Step 2: 政策提出UXを作る

- 選択国の手札だけを下部に出す。
- 政策カードを選ぶと、選択国の政策案スロットへ移動する。
- 同時公開までは裏向きにする。

### Step 3: ワーカー配置UXを作る

- ワーカートレイから印章を選ぶ。
- 選択国の担当印スロットに押印する。
- 印は公開情報として残す。

### Step 4: 同時公開を作る

- 4国の伏せ札を一斉フリップ。
- ワーカー印はカード上に残す。
- 国内圧力と世界ボードの関連箇所を発光させる。

### Step 5: 解決処理の段階表示

- 国内圧力判定
- 政策コスト判定
- 国内効果
- 世界波及
- デッキ変質
- マクロフィードバック
- 新聞

### Step 6: 詳細オーバーレイ

- カード詳細
- 国家詳細
- 交渉詳細
- ルール
- 完全ログ

## 11. 完了判定

新UIは、以下を満たしたら一旦合格とする。

- 1280x720で、4国の政策案スロットと担当印スロットが重ならず読める。
- 政策計画中、現在国、政策メニュー、提出先が一目で分かる。
- ワーカー配置中、ワーカーをどこへ置くか迷わない。
- 同時公開前、4国の「伏せ札 + 担当印」が一覧できる。
- ログ欄を読まなくても、国内圧力判定、政策成立、世界波及、デッキ変質が盤面で分かる。
- 世界トラックは表ではなく、危機ボード上のメーターとして見える。
- スコア表は通常時の主役にならない。
- `推奨` は主操作に見えない。

## 12. 実装上の注意

- `GameState.PHASES` は既存ルールの進行として維持する。
- UI状態は別の `GameUiState` として持つ。
- ルール処理と演出処理を分離する。
- 解決処理は最終的にステップ化し、1ステップ送りできるようにする。
- 現行のトークン画像は盤上の駒として使う。余計な二重丸枠を付けない。
- `ResolutionLog` はメイン卓上の主役にしない。新聞/議事録へ格下げする。
