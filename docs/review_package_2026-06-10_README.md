## セッションで確定した主要な結論（要約）

1. v0.1 実装は設計の転写劣化により、中核メカニクス（デッキ変質・マクロ伝達経路）が
   機能していない。原因は設計正本の分裂 → design_v0_2.md に正本を一本化
2. 致命バグ：デッキ循環死・手詰まり経路・RNG下位ビット・信認容量の符号・
   死に効果（administrative_drag / when_commodity_shock / 世界金利 / 貿易開放度）
3. UI：骨抜き判定の両辺（コストと能力値）が盤面に存在しない／ResponsiveLayout は
   到達不能のデッドコード／フォント未同梱（Web書き出しで日本語豆腐化）／
   伏せ札タグ集計の情報リーク — いずれもコードで裏取り済み、§16.8/16.9 に要件化
4. 外部レビュー2本（UI層・知覚UX）は検証の結果ほぼ全件正確。設計書に反映済み
5. validate_data.py は既知の問題を素通しで合格させる（検証強化が PR1 項目）。
   simulate_balance.py は Windows コンソールで文字化け（cp932/UTF-8）
