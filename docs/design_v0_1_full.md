# マクロノミカ 設計書 v0.1

**Game Title:** マクロノミカ  
**Project Name / Repository Name:** `macronomica`  
**Genre:** 国家運営型マクロ経済デッキ構築ゲーム  
**Target Players:** 4 players  
**Target Version:** v0.1 playable prototype  
**Status:** Design Draft  
**Language:** Japanese-first, code/data IDs in English  

---

## 1. 企画概要

『マクロノミカ』は、各プレイヤーが異なる国家を担当し、財政政策・金融政策・通商政策・産業政策・金融規制を組み合わせて、自国経済を運営するゲームである。

各国は孤立していない。貿易、為替、資本移動、金融危機、資源価格、保護主義、世界恐慌、デフレーションを通じて、互いに影響し合う。

ゲームの中心は、以下の緊張関係に置く。

> 自国にとって合理的な政策が、世界全体を悪化させることがある。  
> 世界協調は全員を救うことがあるが、国内政治的には高くつく。

本作は「経済を正確にシミュレートする」ことよりも、「マクロ経済政策の因果とジレンマをプレイヤーに体験させる」ことを重視する。

## 2. 設計目標

### 2.1 体験させたいこと

- 不況時の財政出動が総需要を支える感覚
- デフレが、実質金利上昇・債務負担増・消費先送りを通じて自己強化する感覚
- 金融政策が国内だけでなく、為替・資本移動・世界金利を通じて他国に波及する感覚
- 関税、通貨安、輸出補助金などの近隣窮乏化政策が、短期的には魅力的だが世界経済を悪化させる感覚
- 公共選択論により、社会的に望ましい政策が政治的には通りにくい感覚
- 国家の産業構造・通貨体制・政治制度によって、有効な政策が変わる感覚

### 2.2 学習テーマ

- ケインズ経済学
- ニューケインジアン的な期待・金融政策
- 貨幣論・信用創造
- 財政政策と政府債務
- 国際マクロ経済
- デフレーションと世界恐慌
- 公共選択論
- 政策決定コスト
- 産業構造・国家制度・経済脆弱性

## 3. ナショナルエコノミーとの差別化方針

本作は経済循環を扱うが、ナショナルエコノミー的な「職場に労働者を置く」「建物を建てる」「給料日に追われる」「家計・金庫でお金を回す」という骨格は採用しない。

### 3.1 採用してよい抽象的な美点

- 経済が循環している感覚
- 限られた資源で意思決定する苦しさ
- 短期利益と長期リスクのトレードオフ
- カードとトラックで複雑な経済を表現する手軽さ

### 3.2 避けるもの

- 労働者を職場に置いて資源を得る構造
- 建物カードを建てて自分専用アクションにする構造
- 家計・金庫のような資金プール構造
- 給料日的な固定支払い圧
- 建物価値＋現金で最終スコアを出す構造
- 公開説明で「ナショナルエコノミー風」と書くこと

### 3.3 本作の独自性

- 各プレイヤーが別々の国家を担当する
- 国家構成からデッキが生成される
- 政策により国家デッキが変質する
- 国内政治・国際交渉・世界危機が政策を制約する
- ワーカーは資源獲得ではなく、政策形成・行政実施・交渉に使う

## 4. プレイヤー構成

プレイヤー数は4人を基本とする。

各プレイヤーは、それぞれ異なる国家を担当する。

v0.1では、以下の4国家プリセットを用意する。

| 国家 | 概要 | 強み | 脆弱性 |
|---|---|---|---|
| A国：基軸通貨・金融大国 | 巨大な内需と金融市場を持つ | 国債発行、金融政策、スワップライン | 金融バブル、格差、世界波及責任 |
| B国：輸出工業・デフレ国 | 製造業と輸出が強い | 産業政策、技術投資、輸出競争力 | 外需依存、デフレ、高齢化 |
| C国：資源国 | 資源輸出に依存 | 資源収入、安定化基金 | 資源価格暴落、汚職、産業単一化 |
| D国：新興・外貨債務国 | 成長率が高いが外貨債務を抱える | インフラ投資、都市化、高成長 | 資本流出、通貨危機、外貨準備不足 |

## 5. 国家構成とデッキ生成

本作の中心システムは、国家構成によるデッキ生成である。

プレイヤーは国家を固定キャラクターとして受け取るのではなく、複数の国家構成モジュールによって国家を形成する。

### 5.1 国家構成モジュール

国家は以下の5系統のモジュールで構成される。

1. 経済構造
2. 通貨・金融体制
3. 財政構造
4. 政治制度・支持基盤
5. 社会構造・脆弱性

各モジュールは、初期トラック、デッキ追加カード、政策コスト補正、イベント耐性、固有アクションを定義する。

### 5.2 デッキ構成

v0.1では、1国家あたり30〜36枚程度のデッキを想定する。

推奨構成：

| 種別 | 枚数目安 | 内容 |
|---|---:|---|
| 共通政策カード | 8 | 財政刺激、利上げ、関税など |
| 経済構造カード | 8 | 輸出、資源、金融、内需など |
| 通貨・金融カード | 6 | QE、資本流入、外貨債務など |
| 財政・制度カード | 6 | 税制、社会保障、財政硬直化など |
| 国内政治カード | 4 | ロビー、支持基盤、選挙圧力 |
| 脆弱性カード | 4 | デフレ期待、資本流出、資源依存など |

国家デッキは、政策メニューではなく、その国家の能力と呪いを同時に表す。

### 5.3 デッキに入る悪いカード

- デフレ期待
- 外需依存
- 資源価格依存
- 高齢者医療費
- 財政硬直化
- 輸出企業ロビー
- 銀行部門の過剰債務
- 外貨建て債務
- 住宅バブル
- 改革疲れ
- 保護産業ロビー
- 汚職・レントシーキング

### 5.4 プレイ中のデッキ変質

政策は即時効果だけでなく、将来の国家デッキを変える。

例：量的緩和を続ける

```text
即時効果：
金利低下、需要増、為替安

デッキ変化：
「資産価格上昇」を追加
「金融不均衡」を追加
信認が低い場合、「通貨不安」を追加
```

例：構造改革を通す

```text
即時効果：
政治資本 -3、短期失業 +1

デッキ変化：
「生産性上昇」を追加
「既得権益の反発」を追加
「財政硬直化」を1枚除去
```

例：関税を使う

```text
即時効果：
特定産業雇用 +1、政治資本 +1

デッキ変化：
自国デッキに「保護産業ロビー」を追加
世界デッキに「報復関税」を追加
保護主義トラック +1
```

## 7. ターン構造

4人同時進行を基本とする。

```text
1. 世界イベント公開
2. 各国の国内情勢更新
3. 国際交渉フェーズ
4. 各国政策計画フェーズ
5. 政策ワーカー配置
6. 同時公開
7. 政策成立判定
8. 国際波及処理
9. マクロ指標更新
10. 国内政治・選挙処理
11. デッキ変質処理
```

### 7.1 世界イベント公開

世界イベントデッキから1枚公開する。

例：

```text
世界需要急減
世界需要 -2
各国輸出 -1
輸出依存国は追加でGDPギャップ -1
世界恐慌 +1
```

### 7.2 国内情勢更新

各国は国内圧力カードを引く。

例：

- 輸出企業が通貨安を要求
- 労働者が雇用対策を要求
- 債権者が利上げを要求
- 高齢者層が社会保障削減に反発
- 金融業界が救済を要求

### 7.3 国際交渉フェーズ

プレイヤーは協調政策や取引を交渉する。

交渉対象：

- 同時財政刺激
- 関税凍結協定
- 国際スワップライン
- 債務再編
- 資源価格安定協定
- 共同利下げ
- 金融安定基金

約束は必ずしも拘束的ではない。政策同時公開時に裏切りが発生しうる。

### 7.4 政策計画とワーカー配置

各国は秘密裏に政策カードを選び、ワーカーを割り当てる。

### 7.5 同時公開

全員が政策を公開する。

ここで協調、裏切り、近隣窮乏化、報復が明らかになる。

### 7.6 政策成立判定

政策コストを確認する。

各政策は以下のコストを持つ。

- 財政コスト
- 政治コスト
- 行政コスト
- 信認コスト
- 国際コスト
- 実施ラグ

コスト不足の場合、政策は以下のいずれかになる。

- 延期
- 骨抜き
- 補助金混入
- 特定業界向けに歪む
- 汚職リスク追加
- 実施ラグ増加
- 国際的反発

### 7.7 国際波及処理

政策の国際効果を処理する。

例：

```text
基軸通貨国が利上げ
→ 世界金利 +1
→ 新興国に資本流出圧力
→ 外貨債務国の金融ストレス +1
```

### 7.8 マクロ指標更新

各国の国家トラックと世界トラックを更新する。

### 7.9 国内政治・選挙処理

支持率、政治資本、社会不安、ロビー影響力を更新する。

### 7.10 デッキ変質処理

政策や危機の結果に応じて、カードを追加・除去・強化・弱体化する。

## 8. マクロモデル

本作は精密なDSGEモデルではなく、ボードゲーム用に抽象化されたマクロモデルを採用する。

### 8.1 需要インパルス

```text
需要インパルス
= 財政政策効果
+ 金融政策効果
+ 輸出効果
+ 信用効果
+ 期待効果
+ 世界イベント効果
```

### 8.2 GDPギャップ更新

```text
GDPギャップ
= 前期GDPギャップ
+ 需要インパルス
- 供給制約
- 世界需要ショック
```

### 8.3 失業更新

```text
GDPギャップがマイナス → 失業上昇
GDPギャップがプラス → 失業低下
```

ただし、供給ショック時にはGDPギャップが悪化してもインフレが上がることがある。

### 8.4 インフレ更新

```text
インフレ変化
= GDPギャップ効果
+ 供給ショック
+ 期待インフレ
+ 為替安による輸入物価
- 中央銀行信認
```

### 8.5 政府債務更新

```text
政府債務
= 前期債務
+ 財政赤字
+ 利払い
- 成長による負担軽減
```

### 8.6 為替更新

```text
為替
= 金利差
+ 経常収支
+ 資本流入/流出
+ 信認
+ 為替介入
```

### 8.7 金融ストレス更新

```text
金融ストレス
= 民間債務
+ 資産バブル
+ 世界金融不安
+ 通貨安による外貨債務負担
- 銀行規制
- 流動性供給
```

## 9. デフレーション設計

デフレは単なる低インフレではなく、自己強化する危機として扱う。

### 9.1 デフレ効果

- 実質金利上昇
- 民間債務負担増
- 政府債務負担増
- 消費先送り
- 投資先送り
- 金融政策の効果低下
- 失業増加
- 税収減少

### 9.2 デフレスパイラル判定

```text
インフレ <= 0
かつ
GDPギャップ < 0
かつ
期待インフレが低い
```

この条件を満たすと、デフレスパイラルが進行する。

効果：

```text
消費 -1
投資 -1
失業 +1
税収 -1
債務負担 +1
金融ストレス +1
```

---

## 10. 世界恐慌設計

世界恐慌は単発イベントではなく、共有危機トラックとして扱う。

### 10.1 世界恐慌トラック

世界恐慌トラックが上がる要因：

- 世界需要の低下
- 国際金融不安の上昇
- 保護主義の上昇
- デフレ期待の固定化
- 大国の金融危機
- 同時緊縮

世界恐慌トラックの効果：

```text
各国輸出 -1
投資 -1
失業 +1
デフレ圧力 +1
金融ストレス +1
```

### 10.2 協調政策

協調政策は参加国が多いほど効果が大きい。

例：同時財政刺激

```text
2国参加：世界需要 +1
3国参加：世界需要 +2、信用収縮 -1
4国参加：世界需要 +3、信用収縮 -2、デフレ期待 -1
```

ただし、協調政策には国内政治コストがある。

## 11. 公共選択論と政策決定コスト

政策は、経済的に望ましいだけでは実行できない。

各政策には以下のコストを持たせる。

| コスト | 意味 |
|---|---|
| 財政コスト | 国債発行・税収減・歳出増 |
| 政治コスト | 選挙、支持率、連立、ロビー抵抗 |
| 行政コスト | 実施能力、制度設計、執行負荷 |
| 信認コスト | 中央銀行信認、財政信認、国際信認 |
| 国際コスト | 他国反発、報復、協調低下 |
| 実施ラグ | 効果発現までの遅れ |

### 11.1 政策例：増税

```text
効果：税収 +3、財政信認 +1
副作用：消費 -2
政治コスト：4
選挙前：政治コスト +2
不況時：社会不安 +1
デフレ中：デフレ期待 +1
```

### 11.2 政策例：補助金

```text
効果：特定産業雇用 +1、政治資本 +1
財政コスト：2
副作用：レントシーキング +1、財政硬直化 +1
```

### 11.3 政策例：規制改革

```text
効果：長期潜在GDP +2
副作用：短期失業 +1
政治コスト：4
行政コスト：2
既得権益が強い国：政治コスト +2
危機時：政治コスト -1
```

## 12. 国際波及と近隣窮乏化政策

### 12.1 貿易波及

```text
ある国の財政出動
→ その国の需要増
→ 輸入増
→ 他国の輸出増
```

```text
全員が緊縮
→ 世界需要低下
→ 全員の輸出悪化
→ 世界恐慌進行
```

### 12.2 為替波及

```text
利上げ
→ 通貨高
→ 輸入物価低下
→ 輸出悪化
```

```text
利下げ/QE
→ 通貨安
→ 輸出改善
→ 輸入インフレ
```

### 12.3 資本移動

```text
高金利・高信認の国へ資本流入
低信認・高債務の国から資本流出
```

### 12.4 近隣窮乏化政策

例：関税

```text
自国：特定産業雇用 +1、政治資本 +1
他国：輸出 -1
世界：保護主義 +1、世界需要 -1
```

例：競争的通貨安

```text
自国：輸出 +2、輸入インフレ +1
他国：輸出 -1
世界：通貨戦争 +1、国際協調 -1
```

## 13. 勝利条件・スコアリング

スコアは3層にする。

### 13.1 自国スコア

- 国民厚生
- 雇用
- 物価安定
- 潜在成長力
- 金融安定
- 財政安定
- 社会安定

### 13.2 国家別レガシー目標

| 国家タイプ | レガシー目標 |
|---|---|
| 基軸通貨大国 | 世界金融秩序を維持する。基軸通貨信認を守る |
| 輸出工業国 | 輸出競争力と技術力を高める。デフレを避ける |
| 資源国 | 資源依存を減らす。安定化基金を育てる |
| 新興国 | 高成長を維持する。通貨危機を避ける。外貨準備を確保する |

### 13.3 世界危機ペナルティ

世界経済が壊れると全員が大きく減点される。

条件例：

- 世界恐慌トラック最大
- 国際金融不安最大
- 保護主義最大
- デフレスパイラル固定化

世界危機が極端に悪化した場合、全員敗北ルールも検討する。

## 15. 開発環境方針

### 15.1 推奨方針

v0.1は **Godot-first** で開発する。

理由：

- ボードゲームアプリとして早期に見た目を作れる
- カード、トラック、国家ボード、世界ボードのUIを組みやすい
- 公開デモとして見せやすい
- オープンソース開発と相性がよい
- Web書き出しにより、ブラウザ体験版を公開しやすい

ただし、ゲームロジックはUIから分離する。

```text
Godotを使うが、Godotの画面にルールを埋め込まない。
カード・国家構成・イベントはデータファイルで管理する。
ルール解決はcore層に閉じ込める。
UIはcoreの結果を表示するだけにする。
```

### 15.2 採用技術

- Engine: Godot 4.6.x
- Language: GDScript
- Data: JSONまたはYAML
- Dev Tools: Python 3.x for data validation and balance simulations
- Repository: GitHub
- Distribution: Web export, desktop export

### 15.3 C#を避ける理由

Godot 4系では、C#プロジェクトのWebエクスポートに制限がある。Web公開を重視するなら、v0.1ではGDScriptを選ぶ。

### 15.4 2D/UI中心で作る

本作は3Dゲームではなく、ボード・カード・トラックを扱う2D/UIゲームとして作る。

Godotでは以下のようなScene構成にする。

```text
MainScene
├── WorldBoard
├── CountryBoards
├── HandArea
├── PolicyPlanningPanel
├── NegotiationPanel
├── ResolutionLog
└── EndTurnControls
```

## 21. v0.1の成功条件

v0.1の成功条件は、以下を満たすこと。

- 4国家が異なる手触りで動く
- 世界イベントが各国に違う影響を与える
- 政策の短期効果と長期副作用が分かる
- 国内圧力により、最適政策が歪む
- 近隣窮乏化政策が使いたくなる
- 使いすぎると世界恐慌が悪化する
- 協調政策が強いが、国内政治コストが痛い
- 政策によってデッキが変質し、国家の歴史が残る
