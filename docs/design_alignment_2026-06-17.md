# マクロノミカ 設計整合レビュー（2026-06-17）

この文書は、`docs/design_v0_2.md` と、直前の設計会話で提示された設計観点を基準に、
現実装がゲームデザインとしてどこまで一致しているかを整理する。

## 判定

**コアルールは、会話で描かれたゲームデザインにかなり近づいた。**

政策デッキ廃止、状態デッキ、マクロ伝達、毎ターン厚生点、選挙、共同宣言、支援要請、双方向ターゲット政策は実装に入っている。
さらに今回、会話の中心だった **「国家構成が政策選択肢・脆弱性・リスクの違いを生む」** 部分を実装に入れた。
各モジュールは `policy_cards` を持ち、政策メニューは国家構成から生成される。
世界イベントはタグ別に状態カードや危機政策を注入し、公開状態カードの `response` はAIの政策/ワーカー選択とUI上の対応対象選択にも反映される。

## 整合している点

| 設計観点 | 現状 | 判定 |
|---|---|---|
| 4人がそれぞれ国家を担当する | 4国家プリセットで進行 | ○ |
| 半競争・半協力 | 自国スコア、共同宣言、全員敗北がある | ○ |
| 政策デッキ廃止 | 政策は `policy_menu`、状態デッキは政策を含まない | ○ |
| デッキは国家の体質・歴史 | 12枚状態デッキ、毎ターン2枚公開、mutationsで追加/除去 | ○ |
| 政策ゼロ・手詰まり対策 | 政策は常設メニュー、プレイテストで政策不在0 | ○ |
| マクロ経済の相互連関 | 世界需要、貿易、金利、期待、利払い、資本移動、デフレスパイラルがある | ○ |
| 公共選択の制約 | 圧力タグ、骨抜き連動、選挙前政治コストがある | ○ |
| 近隣窮乏化と全員敗北 | 関税・輸出補助、保護主義、恐慌10で全員敗北 | ○ |
| 双方向ターゲット政策 | `swap_line` / `debt_restructuring` は対象国指定 | ○ |
| 最低限の交渉の器 | 共同宣言、裏切りペナルティ、支援要請、支援履行の見返りがある | ○ |
| 国家構成＝政策選択肢 | 各モジュールが `policy_cards` を持ち、政策メニューに反映される | ○ |
| 世界イベントの非対称デッキ汚染 | `add_state_cards` / `add_policy_menu` でタグ別注入 | ○ |
| 状態カード response | 公開状態カードへの対応が政策評価・ワーカー選択・対応対象選択に反映される | ○ |

## 未達の点

| 会話での設計 | 現状の不足 | 影響 |
|---|---|---|
| ワーカーは政策・危機・交渉案件に割り当てる | 状態対応は選択対象としてUIに出る。交渉案件は支援要請と誓約でコア化 | より専用UIにする余地はある |
| 国内圧力カード・悪い状態への対応体系 | `response` はAI評価・明示対象選択・ログに入った | 呪いを「除去するか抱えるか」として扱える |
| 交渉で取引材料が生まれる | 支援要請、支援履行、影響力の見返り、明示誓約の不履行ペナルティがある | 専用交渉UIは今後の磨き込み |
| 教育ゲームとしての因果学習 | マクロ式は入ったが、UIの因果表示・デブリーフはまだ完全ではない | 学習体験は実装よりUIに依存して未完成 |
| マクロ理解者が勝つ | `compare_macro_ai.gd` でマクロAIが単純加算AIを大幅に上回った | 成功条件8は暫定達成 |

## 現時点の自動プレイ指標

`tools/playtest_game_design.gd` 120回：

```text
Stuck games: 0
Missing policy menu observations: 0
Pressure satisfaction rate: 28.9%
Global collapse rate: 5.8%
Target policy target-selected rate: 100.0%
Findings: 停止・政策不在・対象未選択なし
```

これは「政策デッキ廃止後にゲームが壊れていない」ことに加え、
公共選択の苦しさ（圧力満足率が高すぎない）と世界恐慌の脅威（全員敗北が現実に見える）が最低限残っていることを示す。
加えて `tools/compare_macro_ai.gd` 40 seed 同一条件比較では、マクロAIが単純加算AIを
平均 +129.2 点/国 上回った（単純AIは全員敗北率 80.0%）。「マクロを読む方が勝つ」という
学習ゲームとしての成功条件は暫定的に満たした。

## 結論

現実装は、会話で描かれた設計の **コアループ** には到達しつつある。
特に、

```text
国家構成が政策選択肢を生み、
世界イベントと政策が国家デッキを変質させ、
国家ごとに違うリスクと有効政策が立ち上がる
```

という部分は、データとコアロジックに入った。

次に残るのは、コアルールではなく体験化である：

1. 支援要請・対応対象選択を専用UIとして読みやすくする
2. デブリーフ画面と因果ログを強化し、なぜ勝敗が分かれたかを人間に説明できるようにする
