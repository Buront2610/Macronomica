# ルール v0.1

## ターン

1. 世界イベント公開
2. 国内情勢更新
3. 国際交渉
4. 政策計画
5. ワーカー配置
6. 同時公開
7. 政策成立判定
8. 国際波及処理
9. マクロ指標更新
10. 国内政治処理
11. デッキ変質処理

Godot MVPでは、世界イベント公開と国内情勢更新はターン開始時に自動処理されます。その後、プレイヤーは `国際交渉 -> 政策計画 -> ワーカー配置 -> 同時公開 -> 解決` の順でフェーズを進めます。

## ワーカー

- 官僚団: 行政コストを1下げる
- 中銀スタッフ: 金融政策の信認コストを1下げ、金融ストレス上昇を抑える
- 外交官: 国際コストを1下げ、協調政策を強化する
- 監査官: 汚職やレントシーキング由来のデッキ汚染を抑える
- ロビイスト: 政治コストを1下げるが、利権カードを追加する

## MVP UI

- 画面は卓上ボードとして構成されます。
- 左に世界ボード、中央に国際交渉テーブルと4国家マット、右に解決ログがあります。
- 各国家マットには、国内圧力カード、政策案スロット、ワーカートークン、国家トラック、手札、山札/捨て札枚数が表示されます。
- 手札の `政策` は選択できます。
- 手札の `状態` は、国家デッキに混ざる歴史・脆弱性・制度カードです。政策としては選べません。
- 政策案は同時公開フェーズまで伏せ札として表示されます。
- ワーカーは政策案スロットに割り当てるトークンとして扱います。
- `全員に推奨案` はテストプレイ用の補助機能です。国内圧力、デフレ、金融ストレス、世界恐慌を見て政策を自動選択します。
