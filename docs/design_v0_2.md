## 0. この文書の位置づけ

v0.1 の設計は「設計会話 → 設計書 → 実装」と転写されるたびに背骨が抜け落ち、
実装は自らのMVP定義（世界波及・デッキ変質）を満たさない状態に至った。
本書はその教訓を踏まえ、**設計の正本をこの1ファイルに統合する**。
以後、実装・データ・テストはすべて本書を参照し、本書にない仕様を実装しない。
本書を変更せずに仕様を変えることを禁止する。

## 1. 不変の核（設計原則 12か条）

1. 各プレイヤーは国家を担当する
2. 国家はモジュールで構成される
3. 国家構成が政策カタログと状態デッキを生成する
4. 旧式の混合政策デッキ（政策・状態を同じ山札から引く構造）は廃止する。
   ただし政策カタログは編集可能なデッキとして残し、毎ターンの政策議題を生成する
5. 政策によってデッキは改善も悪化もする
6. 世界イベントは全員に影響するが、国家構成によって効き方が違う
7. 国内政策は国際的に波及する
8. 自国に合理的な政策が世界全体を悪化させることがある
9. 公共選択論により、良い政策ほど通りにくいことがある
10. ワーカーは資源獲得ではなく、政策形成・実施・交渉に使う
11. 勝利条件はGDP最大化ではなく、国民厚生・安定・国家目標・危機管理の総合評価
12. 世界恐慌やデフレは単発イベントではなく、自己強化する危機として扱う

### 一文要約

> 各プレイヤーが異なる国家構造を持つ国を運営し、財政・金融・通商・産業政策を、
> 国内政治と国際経済の制約下で決定し、世界恐慌やデフレ、金融危機を乗り越えながら、
> 自国の厚生と国際的地位を競うマクロ経済・国家デッキ変質ゲームである。

### ナショナルエコノミーとの距離（維持）

借りる：経済が循環している感覚／限られた資源で意思決定する苦しさ／短期利益と長期リスクのトレードオフ／カードとトラックの手軽さ。
避ける：職場配置による資源獲得／建物構築／家計・金庫の資金プール構造／給料日的固定支払い圧／資産価値スコア。
循環の感覚は**プールではなく国際波及（§7）で出す**。エスカレーションの時計は**賃金ではなく選挙（§9）で出す**。

## 3. プレイ基本

```text
プレイヤー数：4（各自が1国家を担当）
ターン数：10
国家プリセット：4種（A:基軸通貨・金融大国 / B:輸出工業・デフレ国 / C:資源国 / D:新興・外貨債務国）
国家構成モジュール：5系統 × 各国1（経済構造 / 通貨・金融体制 / 財政構造 / 政治制度 / 社会構造）
政策カタログ：各国 12〜18枚前後（政策能力の束。毎ターン4枚程度が議題化）
政策議題：各国 4〜7枚（基本政策＋カタログ公開＋状態/圧力/交渉/危機で補正）
状態デッキ：各国 12枚
世界イベント：単発ショック・持続危機の2分類（構造変化は v0.3）
```

将来構想：国家編成（モジュール5系統から1つずつ選び国家を自作）。
このため **country_id への分岐をコアロジックに書くことを禁止**し、
すべてモジュール・タグ・データ定義で表現する（§17）。

## 4. 政策カタログデッキ・政策議題・状態デッキ（v0.2 新規の最重要決定）

v0.1 最大の欠陥は「政策カード」と「国家の体質カード」を同じ山札に混ぜたことにあった。
廃止するのはこの旧式の混合政策デッキであり、政策を所有・編集・変質させる体験そのものではない。
政策は **政策カタログデッキ** として保持し、プレイヤーが毎ターン選ぶのはそこから生成される **政策議題** である。

```text
1. 旧式の混合政策デッキは廃止する。状態カードは政策カタログに混ぜない
2. 各国は政策カタログデッキを持つ。これは国家・政権が持つ政策パッケージの束である
3. ターン開始時、政策カタログデッキから4枚程度を公開して「政策議題」にする。
   選ばなかった議題もターン終了時にカタログ捨て札へ送る。山札切れでシャッフルする
4. 基本政策は安全弁として議題に優先的に出る。基本政策は弱い標準アクションで、クールダウンしない
5. 公開状態カードの response、国内圧力、共同宣言・支援要請、危機政策は政策議題を追加/優先化する
6. 国家デッキは状態カード専用である。脆弱性・レガシー・利権・危機の痕跡だけが入る
7. ターン開始時、状態デッキから2枚公開する（山札が尽きたら捨て札をシャッフル）
8. 公開された状態カードは、そのターンの「国内情勢」である。
   on_turn_start 効果が発火し、コスト容量や状態カード response の対象になる
9. プレイヤーは政策議題から政策1枚を選んで実行する
10. カタログ政策は実行後にクールダウンする。基本政策はクールダウン対象外
11. ターン終了時、公開状態カードを全て捨て札にする
12. mutations 等で獲得する状態カードは**山札の一番上**に置く（次ターンに必ず現れる）
```

- 政策ゼロ・手詰まり・「政策が引けないから何もできない」を構造的に廃止する
- 巨大な全政策メニューから毎ターン探す作業を廃止し、政策会議に上がった4〜7枚へ意思決定を集中させる
- 状態カードの永久残留を廃止する
- 12 により「政策の帰結が翌ターンに顔を出す」即時フィードバックが生まれ、
  デッキ変質の学習可能性が確保される（複数枚獲得時は獲得順に積む）
- 12枚状態デッキ × 10ターン × 2枚 = 20公開 ≒ 1.6周。
  デッキ変質が確率上きちんと顔を出す

## 5. 政策カタログ・政策議題・状態デッキの構成

政策カタログは「国家/政権が持つ政策能力の束」であり、毎ターン全件を選ばせるメニューではない。
政策議題は「今ターン実際に会議に上がった政策候補」である。
状態デッキは **その国の呪い・脆弱性・歴史の束**である。

```text
政策カタログデッキ：
  基本政策を除く共通政策・モジュール由来政策・国際協調政策・危機政策
  12〜18枚前後。編集・追加・劣化・強化の対象

政策議題：
  基本政策             3枚程度（常時安全弁。クールダウンしない）
  カタログ公開          4枚程度
  状態 response / 交渉 / 支援要請 / 危機による優先化を含めて最大7枚

状態デッキ：
  モジュール由来状態   12枚（脆弱性・レガシー・利権。必要に応じて同名複数可）
```

国内圧力カードはデッキに入れず、**独立した圧力デッキから毎ターン1枚公開**する（v0.1実装を踏襲）。

### 状態カードの「対応」フィールド（新規）

すべての悪い状態カードは、除去手段を構造化データで持つ。

```json
{
  "id": "elderly_health_costs",
  "type": "vulnerability",
  "effects": {"on_turn_start": {"debt": 1}},
  "response": {
    "removed_by_tags": ["social_reform"],
    "extra_costs": {"political": 3},
    "election_window_extra": {"political": 2}
  }
}
```

呪いは「ただの被害」ではなく「除去するか抱え続けるかの意思決定」になる。
監査官（§10）はこの除去をワーカーとして担う。

## 6. マクロエンジン（国家トラックの遷移）

### 6.1 国家トラック（9本）

```text
GDPギャップ（-5..+10）   インフレ（-5..+10）   期待インフレ（-5..+5）★v0.2で追加
失業（0..10）            政府債務（0..10）     金融ストレス（0..10）
政治資本（0..10）        為替（-5..+5）        経常収支（-5..+5）
```

### 6.2 世界トラック（5本・全て配線必須）

```text
世界需要（-5..+5）  世界金利（-3..+5）  貿易開放度（0..10）
国際金融不安（0..10）  世界恐慌（0..10）
```

保護主義・国際協調は世界恐慌トラックへの入力として扱い、独立トラックとしては
v0.1 実装の protectionism / global_coordination を維持する（表示は補助扱い）。

### 6.3 毎ターンのマクロ更新（解決フェーズ末尾に、この順で適用）

各ステップは ±1〜2 の階段関数とし、数式を表に出さず処理順とログで因果を示す。

```text
1. 貿易チャネル：
   輸出効果 = sign(世界需要) + (為替 <= -1 ? +1 : 0) + (為替 >= +2 ? -1 : 0) - (保護主義 >= 5 ? 1 : 0)
   各国の gdp_gap と current_account に、モジュール係数 w_trade（輸出工業国=2, 資源国=1, 他=1。内需大国=0..1）を乗じて加算
2. フィリップス曲線：
   gdp_gap >= +2 → inflation +1, unemployment -1
   gdp_gap <  0  → inflation -1, unemployment +1
3. 期待インフレ（適応的期待）：
   期待インフレを実際のインフレへ毎ターン1ステップ近づける。
   信認容量（§13）が高い国は、目標(+2)方向への引き戻しが+1される（アンカリング）
4. 利払い・債務動学：
   世界金利 >= +1 かつ 債務 >= 6 の国 → debt +1
   さらに foreign_debt タグ国は financial_stress +1（外貨建て債務の利払い負担）
5. 資本移動：
   世界金利が今ターン上昇した場合、fragile_currency / foreign_debt タグ国 → 為替 -1, financial_stress +1
   financial_stress >= 7 の国 → 為替 -1（資本逃避）
6. デフレスパイラル判定：
   inflation <= 0 かつ gdp_gap < 0 かつ 期待インフレ <= 0
   → gdp_gap -1, unemployment +1, debt +1, financial_stress +1（ログで「デフレスパイラル」と明示）
7. 金融危機の伝染：
   いずれかの国が financial_stress >= 8 → 国際金融不安 +1、他国全員 financial_stress +1
   （reserve_currency タグ国が発生源の場合は +2 / 他国 +1 を2回 — 大国の危機は重い）
8. 世界恐慌トラック更新：
   世界需要 <= -3 / 国際金融不安 >= 6 / 保護主義 >= 5 / 3国以上の同時緊縮 → 各 +1
   恐慌 >= 6 かつ危機入力が1つ以上残っている場合、自己強化する危機としてさらに +1
   ただし1ターンの増加は最大 +3（危機が重なるほど加速するが、事故死カーブを避ける）
   国際協調 >= 6 → -1（協調による抑制。危機後半は軽い協調では止まらない）
9. 世界恐慌の効果（恐慌 >= 4 の間、毎ターン）：
   全国 gdp_gap -1, unemployment +1, financial_stress +1、デフレ圧力として期待インフレ -1
```

- v0.1 の死に要素はここで全て蘇生する：世界需要・貿易開放度・世界金利は 1/4/5 で読まれ、
  `when_world_demand_negative` 等のカード条件は 1 の輸出効果に統合して廃止する
- `when_commodity_shock` は世界イベント側の `commodity_shock: true` フラグで発火させる（§12）
- 金融政策の効力低下（流動性の罠）：期待インフレ <= -1 の間、金融政策カード（monetary タグ）の
  gdp_gap への効果を -1 する

## 7. 国際波及（政策の国境越え）

政策カードの効果は「自国」「他国（タグ指定 spillover）」「世界」の3層（v0.1実装を維持）に加え、
v0.2 で以下を確定する。

```text
財政出動の漏出：fiscal+demand タグ政策は world_demand +1 を必ず持つ（自国需要の一部が他国の輸出になる）
緊縮の外部性： austerity タグ政策は world_demand -1 を必ず持つ
利上げの輸出： rate_hike は world_interest_rate +1 を必ず持つ（§6.3-4/5 が新興国に波及させる）
通貨安の近隣窮乏化：currency_depreciation は exporter タグ他国に輸出 -1 相当の spillover を持つ
関税の標的：  tariff は exporter タグ他国 spillover に加え、世界デッキに「報復関税」を注入する（v0.1の白眉。維持・拡張）
```

### 双方向ターゲット政策（v0.2 新規）

スワップライン・債務再編は**対象国を指定する**カードに変更する。

```json
{
  "id": "swap_line",
  "target": "country",
  "effects": {
    "donor":    {"political_capital": -1, "influence": 2},
    "recipient": {"financial_stress": -2, "exchange_rate": 1},
    "world":    {"international_financial_instability": -1, "global_coordination": 1}
  }
}
```

これにより交渉フェーズ（§8）に**具体的な取引材料**が生まれる。
「スワップラインを出すから資本規制を控えろ」が、口約束ではなく盤上の行為になる。

## 8. 国際交渉・支援要請・共同宣言

交渉フェーズの原則：**約束は拘束的ではない。裏切りは同時公開で発覚する。**

ただし v0.1 の「完全な飾り」を脱するため、最小の器として**共同宣言**と
**支援要請**を導入する。

### 8.1 共同宣言

```text
1. 交渉フェーズ中、各国は協調案件（同時財政刺激 / 関税凍結 / スワップライン網 / 債務再編会議）に
   「参加宣言」を置ける（宣言は公開・任意・無料）
2. 同時公開時に判定：
   - 宣言通り協調政策を出した国 → 協調スケーリング（下表）の対象、influence +1
   - 宣言したのに違う政策を出した国 → political_capital -2、ログで公開晒し、influence -1
3. 協調スケーリング（参加国数で効果が伸びる）：
   2国：world_demand +1
   3国：world_demand +2、国際金融不安 -1
   4国：world_demand +3、国際金融不安 -2、全国の期待インフレ +1
```

裏切りの自由を保ったまま、裏切りに観測可能なコストを付ける。
AGENDA タイルの既存UIを宣言ボードとして転用する。

### 8.2 支援要請

交渉フェーズ中、各国は議題タイルを使って「この種類の支援が欲しい」と要請できる。
同じ議題に乗った他国、または明示的に支援誓約した他国が、同時公開で該当タグの政策を出した場合、
支援側は国際影響力を得て、要請側はタグ別の救済効果を得る。

```text
流動性 / qe ：要請国の financial_stress -1
債務         ：要請国の debt -1、financial_stress -1
通商         ：要請国の current_account +1
協調         ：要請国の political_capital +1
通貨         ：要請国の exchange_rate +1
```

明示的に誓約した国が該当政策を出さなかった場合は、political_capital -1、influence -1。
単に同じ議題に乗っただけの国は共同宣言の成否で処理し、支援誓約の追加ペナルティは受けない。
これにより、交渉フェーズには「誰が誰を支援するか」「見返りとして影響力を取るか」という
具体的な取引材料が生まれる。

### 8.3 双方向ターゲット政策

スワップライン、債務再編、危機融資などは対象国を指定する。
供与国は influence を得る一方で国内政治・信認コストを払い、受入国は金融ストレスや債務危機を軽減する。
支援要請はこの対象指定政策と組み合わせることで、交渉上の条件付き合意として機能する。

## 9. 選挙タイマー（v0.2 新規・国内政治の時計）

各国は4ターン周期の選挙サイクルを持つ。初期オフセットは国別
（A国: 3ターン目 / B国: 4 / C国: 5 / D国: 6。10ターン中に各国2回選挙が来る）。

```text
選挙前ターン（選挙の1ターン前）：
  - すべての政策の政治コスト +2
  - 圧力カードの if_ignored 効果が2倍
選挙ターン（解決フェーズ末尾に判定）：
  - political_capital >= 5 → 政権維持。political_capital +2
  - political_capital <  5 → 政権交代。political_capital を4に再設定し、
    デッキに「改革疲れ」を1枚追加。進行中の実施ラグ政策（§13）は1つ破棄
```

効果：ゲームに周期的な山場が生まれ（アーク問題の解消）、
「選挙前に痛い改革は通らない」という公共選択論の中心命題がルールとして体験される。
ナショナルエコノミーの賃金上昇に相当する時計を、禁止事項（給料日圧）に抵触せず実現する。

## 10. ワーカー＝政策遂行能力（マルチ割当）

各国はワーカー5体（官僚団・中銀スタッフ・外交官・監査官・ロビイスト）を持ち、
毎ターン**複数のワーカーを以下の任務に自由に配分**する（1任務1体まで、未割当可）。

```text
政策実施（選択した政策カードに付ける。複数可）：
  官僚団      ：行政コスト -1
  中銀スタッフ ：信認コスト -1。さらにこのターン自国の financial_stress 上昇を1軽減
  外交官      ：国際コスト -1。協調政策なら世界効果 +1（共同宣言の成立を助ける）
  ロビイスト   ：政治コスト -2。ただし山札の上に「レントシーキング」を追加
監査任務（政策に付けず単独で）：
  監査官      ：自国デッキ/捨て札から corruption_risk / rent_seeking / patronage_network を1枚除去
対応任務（状態カードの response を実行）：
  任意のワーカー＋必要コスト支払いで、手札の状態カード1枚を除去（§5）
```

- v0.1 の「1体だけ・自明解・監査官が常に劣後」を解消する。
  デッキ変質が機能する v0.2 では監査官・対応任務に恒常的な価値がある
- レントシーキングの効果は `administrative_drag`（死にトラック）を廃止し、
  「手札にある間、行政コスト +1」に変更する（手札通過型なので確実に機能する）
- ルール文書 v0.1 のワーカー能力（中銀スタッフのストレス抑制、外交官の協調強化）をここで実装する
- 危機管理班・選挙対策チーム・広報チームは v0.3 候補（§18）

## 11. スコアリング（3層＋毎ターン採点）

### 11.1 毎ターン厚生点（フローの採点 — v0.2 新規）

各ターン終了時、各国は 0〜4 点の厚生点を積み上げる：

```text
+1 : gdp_gap が 0..+1（目標帯。過熱も不況も加点しない）
+1 : unemployment <= 3
+1 : |inflation - 2| <= 1（物価目標）
+1 : financial_stress <= 4
```

経路そのものが成績になる。「最終ターンだけ帳尻を合わせる」終端ゲームを排除し、
中間順位が常時可視化される。

#### 11.1.1 理論的根拠

厚生点は、ニューケインジアン・マクロの標準的な社会損失関数
`L = (インフレ − 目標)² + λ(GDPギャップ)²`（＋2008年以降の拡張としての金融安定項）を
ボードゲーム用に離散化したものである。各条件の対応：

```text
|inflation − 2| <= 1 ：インフレ目標2％±1のターゲットバンド（実在の中銀の枠組み）
gdp_gap 0..+1       ：産出ギャップの安定化。過熱側に寄せた非対称バンドは、
                      低インフレ環境ではデフレリスク側のコストが高いというZLB研究と整合。
                      なお採点バンドは対称性を保ち、デフレの非対称な厚生コストは
                      動学側（§6.3-6 スパイラル）が担う分担とする
unemployment <= 3   ：雇用の最大化（デュアルマンデート）。ギャップとの情報重複（オークン法則）は
                      承知の上で残す — 失業はギャップから遅れて動くストックであり、
                      「ギャップを早く閉じないと失業が残る」という時間差自体が教材になる
financial_stress <= 4：金融安定。厳密には中間変数だが、マクロプルーデンス以降の
                      政策目標としては標準
```

**意図的な除外項目**（これ自体が設計判断であり、変更時は本節の根拠を覆すこと）：

```text
政府債務・財政赤字：厚生から除外する。債務は厚生の引数ではなく異時点間の「制約」であり、
  現行のマクロ経済学でも債務残高そのものを厚生損失とは扱わない
  （r < g 環境下では債務の財政コストは従来想定より小さい、という2019年以降の主流見解とも整合）。
  ゲーム内では債務は採点ではなく、財政容量（§13）と利払い動学（§6.3-4）という
  「制約とリスク」の側でのみ効く。v0.1 が債務を直接減点していたのは理論的に誤りで、v0.2 で廃止した
経常収支・為替：経常黒字は厚生ではない（重商主義の誤謬）。ただし圧力カード（輸出企業ロビー等）は
  政治的にはプレイヤーを黒字追求へ押す — 「政治は黒字を欲しがるが厚生には寄与しない」
  という緊張関係は意図された教材である
政治資本：手段であって国民厚生ではない（v0.1 の直接加点を廃止）
```

**既知の理論的限界**：

```text
水準の欠落：本関数は安定化（ブレの小ささ）のみを測り、豊かさの水準・成長を測らない。
  長期厚生を支配するのは潜在産出の成長だが、本作は意図的に
  「安定化政策と危機管理のゲーム」としてスコープを切っている。
  v0.3 で潜在成長力トラックを導入する際は、厚生点へ第5条件として接続すること（§19 に予約）
閾値の崖：理論の2次損失と異なり、バンド外の改善に報酬勾配がない。
  検討中の調整案：4条件すべて達成で +1 のボーナス（合計 0〜5 点化）。採否は未決定
```

### 11.2 最終評価

```text
最終スコア = Σ毎ターン厚生点
           + レガシー目標（目標カード。条件を構造化データで定義し、編成時に国家タイプから付与）
           + 国際影響力 × 2（influence トラック。スワップ供与・共同宣言遵守・債務再編主導で増加）
           - 世界危機ペナルティ（恐慌レベル × 国別エクスポージャー係数：
             輸出工業国 2 / 資源国・新興国 1.5 / 内需・基軸通貨国 1）
```

gdp_gap の線形加点（過熱インセンティブ）は廃止。
一律減点は廃止し、エクスポージャー係数で非対称化する。

### 11.3 全員敗北

**世界恐慌トラックが 10 に達した時点でゲーム即終了・全員敗北**（スコア無効・勝者なし）。
恐慌 8 以上で全国のUIに崩壊警告を常時表示する。
「協調しないと世界が壊れる。協調しすぎると自国が損をする」をルール1行で成立させる。

## 12. 世界イベント

### 12.1 2分類（v0.2）

```text
単発ショック（即時効果のみ）：
  資源価格急騰/急落（commodity_shock フラグ）、世界金利上昇、主要国銀行破綻、
  サプライチェーン寸断、地政学リスク
持続危機（専用カウンター。解除条件を満たすまで毎ターン効果）：
  国際金融危機（解除：国際金融不安 <= 3）、保護主義連鎖（解除：関税凍結協定の成立）、
  債務危機連鎖（解除：債務再編の実行）
構造変化（ルール自体の変更）は v0.3 へ送る。
```

### 12.2 非対称デッキ汚染（v0.2 新規）

世界イベントは `tagged_countries` のトラック効果に加え、**タグ別に状態カードを山札の上へ注入**できる。
また、特定タグ国だけに危機対応政策を政策カタログへ追加できる。
追加された政策は以後の政策議題に上がりうる。

```text
例：「世界需要急減」
  世界：world_demand -2, depression +1
  exporter タグ国    ：「外需崩壊」を状態デッキ山札の上に追加
  resource タグ国    ：「資源価格暴落」を状態デッキ山札の上に追加
  foreign_debt タグ国：「資本流出」を状態デッキ山札の上に追加
  reserve_currency 国：「最後の貸し手」政策を政策カタログへ追加（国内政治コスト付き）
```

同じイベントが国ごとに違う形で状態デッキや政策カタログに刻まれる。基軸通貨国には危機時にのみ
「責任と特権」の政策選択肢が現れる。

## 13. 政策コストと成立判定

### 13.1 コスト6種＋実施ラグ

```text
財政（debt を増やす） / 政治（political_capital を消費） / 行政 / 信認 / 国際 / 産業（容量判定）
実施ラグ（v0.2 新規）：lag: N を持つ政策は、成立後 N ターン後に効果が発現する（キューに積む）。
MVP では lag 0 または 1 のみ。大型政策（構造改革・インフラ投資）に lag 1 を付与する
```

容量式の修正：

```text
行政容量 = clamp(political_capital + 1 - 手札のレントシーキング枚数, 0, 6)
信認容量 = clamp(8 - financial_stress - max(0, inflation - 2) + (reserve_currency なら +1), 0, 6)
           ※ v0.1 の符号バグ（インフレが信認を上げる）を修正
国際容量 = clamp(current_account + exchange_rate + 3 + influence/3, 0, 6)
```

### 13.2 成立判定の3結果（骨抜き1種からの拡張）

コスト不足の種類によって歪み方が変わる：

```text
政治コスト不足 → 補助金混入：効果は満額だが、財政コスト +1 し、山札の上に「レントシーキング」追加
行政コスト不足 → 延期：効果の実施ラグ +1（来ターンに持ち越し）。圧力は満足しない
その他の不足   → 骨抜き：主要効果半減（切り上げ）＋不足種別の副作用（v0.1実装を維持）
```

### 13.3 圧力との連動（バグ修正を仕様化）

国内圧力の判定は政策の**成立結果の後**に行う。
満額成立 → if_satisfied 満額。骨抜き/補助金混入 → if_satisfied 半減。延期 → if_ignored 扱い。
「実行できない公約でロビーが満額納得する」状態を排除する。

## 14. ターン構造と解決順

```text
1. ターン開始（自動）：世界イベント公開 → 持続危機の効果 → 状態カード2枚公開 →
   公開状態カード発火 → 圧力カード公開 → 実施ラグキューの発現
2. 国際交渉フェーズ：共同宣言の設置・交渉（自由会話）
3. 政策計画フェーズ：各国秘密裏に政策1枚＋ターゲット選択
4. ワーカー配置フェーズ：マルチ割当（§10）
5. 同時公開：宣言遵守/裏切り判定（§8）
6. 解決フェーズ：
   a. コスト容量を全国いっせいにスナップショットで確定（解決順による非対称を排除）
   b. 成立判定（§13.2）→ 圧力判定（§13.3）→ 効果適用・spillover・mutations
      （適用順は毎ターンのローテーション）
   c. マクロ更新（§6.3 の 1〜9）
   d. 選挙判定（該当国のみ。§9）
   e. 毎ターン厚生点の加算と表示（§11.1）
7. ターン終了：手札全捨て → トラック履歴の記録（デブリーフ用）
```

フェーズ定義は実装と1対1対応させる。到達不能フェーズをコアに定義しない
（v0.1 の world_event / domestic_update / resolution 到達不能問題の再発防止）。

## 15. 可読性と学習装置

本作は「マクロ経済学を学ぶ」ゲームである。学習はメカニクスで起こす。

```text
1. 因果ログ：マクロ更新（§6.3）の各ステップは「原因 → 結果」を1行1対で表示する
   例：「B国はGDPギャップがマイナスのため、失業が上昇しデフレ圧力が強まった」
2. 毎ターン採点表示：厚生点の獲得理由（4条件のどれを満たしたか）をターン末に明示
3. デブリーフ画面：ゲーム終了時に全トラックのターン推移グラフを国別に表示する。
   「3ターン目の緊縮からデフレが始まった」を自分の目で発見させる
4. 警告：デフレスパイラル成立の1ターン前（インフレ<=1 かつ ギャップ<0 等）に予告警告を出す。
   予告された痛みは学習であり、予告なしの痛みは事故である
5. 学習目標と担当メカニクスの対応（このどれにも該当しない新機能は追加しない）：
   - 不況時の財政出動はなぜ効くのか          → §6.3-1/2、§7 漏出
   - なぜデフレは厄介なのか                 → §6.3-3/6、流動性の罠
   - なぜ利上げは世界に波及するのか          → §6.3-4/5、§7 利上げの輸出
   - なぜ自国優先が世界を悪化させるのか      → §7、§11.3 全員敗北、報復関税
   - なぜ良い政策ほど通りにくいのか          → §9 選挙、§13 成立判定、圧力カード
   - なぜ国家ごとに有効な政策が違うのか      → モジュール、w_trade、エクスポージャー係数、§12.2
```

（「同じボードでソケットだけ増やす」が通らない）ため、**シーン単位の焼き込みを禁止し、
部品単位で生成・合成する**。v0.1 のトークンアトラス
（1枚生成 → PowerShell切り出し → QAコンタクトシート検証）が手本であり、これをUI部品に拡張する。

**レイヤー別の役割分担**：

| レイヤー | 担当 | 例 |
|---|---|---|
| 雰囲気（焼き込み可） | 生成画像そのまま | テーブル質感背景、ビネット |
| 構造部品 | 生成 → 切り出し → 9パッチ | ソケット、カード枠、パネル縁、飾り板、コーナー装飾 |
| 配置・数・状態 | コード（BoardLayout / PanelFactory） | ソケットの個数・位置、空/装填/ハイライト |
| 動き・影 | Godot（Tween / シェーダ） | ホバー、発火演出、落ち影 |

**生成時の規約**：

```text
1. 部品はシート単位で生成する（single UI element / isolated /
   flat top-down lighting / no cast shadows / plain dark background）。
   方向性のある影・周囲への落ち影を焼き込まない — 影はGodot側で統一して付与する
2. 伸縮する部品（ソケット・パネル枠）は NinePatchRect / StyleBoxTexture 前提の
   単純な額縁構造で生成する。非対称装飾はコーナー部品として別生成して重ねる
3. スタイルの一貫性は、既存トークンアトラスを参照画像として渡して固定する
   （文章指定のみの再生成はスタイルドリフトする）
4. 切り出し・検証は既存ツール（slice_token_atlas.ps1 / validate_token_assets.ps1 /
   QAコンタクトシート）の方式を流用する。透過は単色背景からのキーイングで作る
5. assets/ASSETS.md に素材ごとの生成モデル名・生成日・参照画像の有無・利用条件を1行ずつ記録する
   （同様式での追加生成の再現情報を兼ねる）
```

### 16.8 情報完全性の原則（v0.1 UIレビューの最重要教訓）

**意思決定に必要な情報は、計画フェーズ中に盤面から読めなければならない。**
v0.1 は骨抜き判定の両辺（政策コストと自国の能力値）をどちらも表示しておらず、
中核メカニクスが学習不可能だった。v0.2 のUIは以下を必須とする：

```text
1. 選択中カードの詳細パネル：コスト6種・効果・デッキ変質・波及を常設表示
   （CardTextFormatter.card_detail は実装済み。配線するだけ）
2. 自国トラックの数値表示：トークン/ピップ表現に数値を併記する。
   実物のボードゲームのトラックには必ず目盛りと数字が印刷されている — 雰囲気と数字は両立する
3. コスト充足のプレビュー：政策選択時に「政治 4 / 保有 2 → 補助金混入」のように
   成立判定（§13.2）の予測を表示する（ワーカー割当の効果も反映）
4. トラックレールの記号論統一：双極トラックは中央（ゼロ点）マーカー＋左右色分け、
   インフレは目標帯（1..3）を背景に敷いて現在値マーカー、全レールに数値併記
5. 1字略号は全トラックで一意にする（v0.1 は世界金利と金融ストレスが両方「金」だった）
6. テキストの切断はすべて省略記号付き＋全文へのアクセス手段を保証
   （固定位置 substr によるデータ形式依存の切り出しを禁止）
7. 解決ログの全文は監査可能にする（ヘッドライン圧縮表示とは別に、全文スクロールを提供）
```

### 16.9 知覚・アクセシビリティ要件

```text
1. 日本語フォントを同梱する（Noto Sans JP または M PLUS 1）。
   Web書き出しにはシステムフォントが存在せず、未同梱では日本語が全て豆腐になる。PR1で実施
2. 最小フォントサイズ 13px（§16.4。一様縮小後の実効サイズで可読性を保つ下限）
3. テキストを載せるパネルは不透明度 α >= 0.9。輝度分散の大きい生成背景への
   半透明パネル＋直置きラベルは局所コントラストが制御不能になるため禁止
4. 色のみのエンコーディングを禁止する。状態の良し悪しは色＋形状/数値の冗長表現とする
   （リスクチップに数値併記、圧力の成否に ✓/✗、双極レールの左右色分け＋マーカー）
5. モーションは「状態が変わった要素」にのみ発火させる（v0.1 は国切替だけで中央卓がバウンスしていた）。
   設定にモーション削減オプションを置く
6. 操作品質基準：
   - 演出・装飾ノード（ゴースト、トレイル、ピップ）は MOUSE_FILTER_IGNORE 必須
   - ホバー演出は scale / 描画オフセットに限定（position の tween は他演出と競合するため禁止）し、
     退出時は保存した元値（z_index 含む）へ復元する
   - クリックは左ボタンのみ・リリース時確定（ドラッグ離脱キャンセル可能）
   - 無効な操作には理由を提示する（例：「状態カードは政策として出せません」のトースト）
   - 破壊的操作（ゲーム破棄）には確認を挟む
   - 全画面オーバーレイは背面入力を遮断するスクリムを必須とする
7. 秘匿情報のゲート：伏せ札に由来するあらゆる表示（タグ集計ピップを含む）は
   game.revealed_policies でゲートする（v0.1 は交渉テーブルのピップが計画中に漏れていた）
```

## 17. データ・実装方針

```text
- コアロジックに country_id 分岐を書くことを禁止する。国家差はすべて
  モジュール / タグ / カードデータ / 係数（w_trade 等はモジュール属性）で表現する
  （deck_builder.gd と scoring.gd の既存分岐は JSON へ移行する）
- レガシー目標は「目標カード」としてJSON定義する（条件は構造化データ。式の文字列評価は禁止）
- RNG は Godot 標準 RandomNumberGenerator + seed（自作LCGは廃止）
- ドメイン層は構造化イベント（ResolutionResult）を返し、文章化はUI層が行う
- validate_data.py は以下を検証する：全ファイル横断のID一意性 / 参照整合 /
  効果キー・条件キー・タグが実装の許可リストに存在すること（死に効果の再発防止）/
  デッキ構成枚数（§5）
- 受入基準：§15-5 の6項目をプレイテスト・チェックリストとし、モンテカルロ
  （PolicyRecommender ベースのAI対戦数百回）で以下を確認する：
  4国家の勝率が 15%〜35% に収まる / 全員敗北率が 5%〜20% / 
  「動学を読むAI」が「カード算術AI」に有意に勝つ（マクロ理解がスキルである検証）
```

## 20. v0.2 の成功条件

v0.1 の成功条件（8項目中達成3）を引き継ぎ、以下をすべて満たすこと：

```text
1. 4国家が異なる手触りで動く（C国の資源ショックが実際に発火する）
2. 世界イベントが各国に違う影響を与える（非対称デッキ汚染を含む）
3. 政策の短期効果と長期副作用が分かる（獲得カードが翌ターン顔を出す）
4. 国内圧力と選挙により、最適政策が歪む
5. 近隣窮乏化政策が使いたくなり、使いすぎると全員敗北が現実に見える
6. 協調政策が強いが、国内政治コストが痛い（共同宣言と裏切りが発生する）
7. 政策によってデッキが変質し、国家の歴史がデッキとデブリーフ画面に残る
8. マクロ経済を理解しているプレイヤーが、理解していないプレイヤーに勝つ
```
