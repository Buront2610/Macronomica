# マクロノミカ

国家運営型マクロ経済デッキ構築ゲーム「マクロノミカ」の Godot プロトタイプです。

このリポジトリは、取り込み済みのレビュー・設計パッケージ `docs/review_package_2026-06-10_README.md` と v0.2 正本 `docs/design_v0_2.md` に沿って、4人ローカルプレイで政策選択、同時公開、世界波及、国内政治、選挙、デッキ変質、最終スコアまで回る版を目指します。

## 現在できること

- 4国家プリセットから国家デッキを生成
- 世界イベントと国内圧力を毎ターン公開
- 各国が手札から政策カードを選択
- 政策ワーカーを割り当て
- 国際交渉、政策計画、ワーカー配置、同時公開、解決処理をフェーズ順に進行
- 同時公開後に政策支払い、国内圧力、国内効果、世界波及、デッキ変質を処理
- 期待インフレ、流動性の罠、貿易チャネル、資本移動、金融伝染を含むマクロフィードバック
- 国際交渉テーブルで共同宣言を置き、遵守時は影響力、違約時は政治資本と影響力に反映
- 国別の選挙タイマー、選挙前ターンの政治コスト上昇、政権交代時の改革疲れを処理
- 政策の成立、骨抜き、補助金混入、実施ラグを分岐して処理
- 世界恐慌、デフレスパイラル予兆、近隣窮乏化、非対称デッキ汚染の基本処理
- 毎ターン厚生点、国際影響力、レガシーボーナスを使った最終スコア表示。世界恐慌が10に達した場合は全員敗北
- 推奨政策ボタンによるローカル4国のクイック進行
- 世界ボード、国際交渉テーブル、国家マット、手札、伏せ札スロット、選挙・厚生・待機政策表示、ワーカートークンを持つ卓上ボードUI
- 1920x1080 基準の `canvas_items` + `expand` による卓上ボードUI

## 遊び方

1. Godot 4.6.x でプロジェクトを開き、メインシーンを実行します。
2. 世界ボードの公開イベントと各国の国内圧力カードを確認します。
3. 国際交渉テーブルで共同宣言を置くか確認します。宣言を守ると影響力が上がり、違約すると政治資本を失います。
4. 各国の手札から `政策` カードを1枚選び、政策案スロットに伏せます。`状態` カードはその国の強みや呪いで、政策としては選べません。
5. 官僚、中銀、外交、監査、ロビーのワーカートークンを政策案に割り当てます。
6. フェーズを進めて `同時公開` し、政策成立、国内政治、世界波及、選挙、厚生点、デッキ変質を解決します。
7. 10ターン後、厚生点・影響力・レガシーを合算した最終順位になります。世界恐慌が10に達した場合は勝者なしの全員敗北です。

迷ったときは `推奨政策` を押すと、国内圧力と危機状況に合わせて全国家の政策を自動選択します。

## 開き方

Godot 4.6.x でこのフォルダをインポートし、`project.godot` を開いてください。

メインシーン:

```text
res://scenes/main/main.tscn
```

PowerShell から直接起動する場合:

```powershell
.\tools\run_godot.ps1
```

## データ検証

```powershell
python tools/validate_data.py
python tools/simulate_balance.py
.\tools\check_godot.ps1
.\tools\check_web_export.ps1
```

v0.2 バランス確認:

```powershell
godot_console --headless --path . --script res://tools/monte_carlo_balance.gd
```

実測結果は `docs/balancing_notes.md` に出力されます。

Web書き出しは `exports/web/` に生成されます。このディレクトリの成果物は再生成可能なためgit管理外です。

## アセット

- `assets/ui/policy_room_background.png`: 生成AIで作成した、政策会議・統計ダッシュボード風の背景画像。外部素材は使っていません。
- `assets/ui/tokens/`: 生成AIで作成したボードゲーム用トークン。政策カード、世界ボード、国家マット、ワーカー表示に使います。

DDD / TDC / DbC 観点の保守方針は `docs/architecture_review.md` にまとめています。
日々の実装ルールとTDD/コンポーネント化の基準は `docs/engineering_playbook.md` にまとめています。
zipから取り込んだ総合レビューは `docs/review_2026-06_full_review.md`、v0.1原典は `docs/design_v0_1_full.md`、v0.2正本は `docs/design_v0_2.md` にあります。取り込み後の実装状況は `docs/review_package_2026-06-10_IMPLEMENTATION.md` にまとめています。

## 方針

- UI は `GameState` を表示し、プレイヤー入力をコマンドとして送るだけに寄せる
- プレイヤー入力に近いユースケース補助は `src/app/` に置く
- 政策処理と不変条件は `src/core/` に集約する
- 状態を持つUI部品は `src/ui/components/` に置く
- 表示名、トークン名、レスポンシブ判定、テクスチャキャッシュは `src/ui/support/` に置く
- カード、国家、モジュール、イベントは `data/` の JSON で管理する
- 乱数はシード管理し、解決ログを残す
