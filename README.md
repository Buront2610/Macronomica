# マクロノミカ

国家運営型マクロ経済デッキ構築ゲーム「マクロノミカ」の v0.1 Godot プロトタイプです。

このリポジトリは、設計書 `docs/design_v0_1.md` に沿って、まず4人ローカルプレイで政策選択、同時公開、世界波及、デッキ変質、最終スコアまで回る最小版を目指します。

## 現在できること

- 4国家プリセットから国家デッキを生成
- 世界イベントと国内圧力を毎ターン公開
- 各国が手札から政策カードを選択
- 政策ワーカーを割り当て
- 国際交渉、政策計画、ワーカー配置、同時公開、解決処理をフェーズ順に進行
- 同時公開後に政策コスト、国内効果、世界波及、デッキ変質を処理
- 世界恐慌、デフレスパイラル、近隣窮乏化の基本処理
- 8ターン終了時にスコア表示
- 推奨政策ボタンによるローカル4国のクイック進行
- 世界ボード、国際交渉テーブル、国家マット、手札、伏せ札スロット、ワーカートークンを持つ卓上ボードUI
- 1280x800 でも操作が破綻しないコンパクトUIと、1680px以上のワイドUI

## 遊び方

1. Godot 4.6.x でプロジェクトを開き、メインシーンを実行します。
2. 世界ボードの公開イベントと各国の国内圧力カードを確認します。
3. 国際交渉テーブルで協調の口約束を読みます。
4. 各国の手札から `政策` カードを1枚選び、政策案スロットに伏せます。`状態` カードはその国の強みや呪いで、政策としては選べません。
5. 官僚、中銀、外交、監査、ロビーのワーカートークンを政策案に割り当てます。
6. フェーズを進めて `同時公開` し、政策成立、国内政治、世界波及、デッキ変質を解決します。
7. 8ターン後、暫定スコアが最終順位になります。

迷ったときは `推奨政策` を押すと、国内圧力と危機状況に合わせて全国家の政策を自動選択します。

## 開き方

Godot 4.6.x でこのフォルダをインポートし、`project.godot` を開いてください。

メインシーン:

```text
res://scenes/main/main.tscn
```

PowerShell から直接起動する場合:

```powershell
.\tools\run_godot.ps1
```

## データ検証

```powershell
python tools/validate_data.py
python tools/simulate_balance.py
.\tools\check_godot.ps1
```

## アセット

- `assets/ui/policy_room_background.png`: 生成AIで作成した、政策会議・統計ダッシュボード風の背景画像。外部素材は使っていません。
- `assets/ui/tokens/`: 生成AIで作成したボードゲーム用トークン。政策カード、世界ボード、国家マット、ワーカー表示に使います。

UI方向性は `docs/ui_direction.md` と `docs/ui_ux_review.md` に整理しています。
DDD / TDC / DbC 観点の保守方針は `docs/architecture_review.md` にまとめています。
日々の実装ルールとTDD/コンポーネント化の基準は `docs/engineering_playbook.md` にまとめています。

## 方針

- UI は `GameState` を表示し、プレイヤー入力をコマンドとして送るだけに寄せる
- プレイヤー入力に近いユースケース補助は `src/app/` に置く
- 政策処理と不変条件は `src/core/` に集約する
- 状態を持つUI部品は `src/ui/components/` に置く
- 表示名、トークン名、レスポンシブ判定、テクスチャキャッシュは `src/ui/support/` に置く
- カード、国家、モジュール、イベントは `data/` の JSON で管理する
- 乱数はシード管理し、解決ログを残す
